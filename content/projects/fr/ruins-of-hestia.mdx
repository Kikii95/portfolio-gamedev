  ## Pitch

  Cali, créature humanoïde du peuple **Primoris**, s'écrase sur la planète **Hestia** suite à un problème moteur. Elle se réveille sans mémoire, recueillie par les **Perséphins**. Avec l'aide d'**Iris**, un jeune Perséphin courageux, elle découvre que la planète est ravagée par la **corruption Harmathys** - un mécanisme de défense activé par l'arrivée des Primoris, qui transforme les habitants pacifiques en créatures agressives.

  ## Genre & boucle de gameplay

  Hybride **gestion de village** + **expéditions action/exploration**. Le joueur alterne entre deux phases :

  ```
  ┌──────────────────┐         ┌──────────────────┐
  │  PHASE VILLAGE   │ ◄─────► │ PHASE EXPÉDITION │
  │  (gestion iso.)  │ cycles  │  (action ZQSD)   │
  ├──────────────────┤         ├──────────────────┤
  │ • Drag & drop    │         │ • Combat         │
  │ • Bâtiments      │         │ • Puzzles        │
  │ • Population     │         │ • Récolte        │
  │ • Héros          │         │ • Boss           │
  └──────────────────┘         └──────────────────┘
  ```

  Chaque expédition consomme un **cycle** village (1 ration/villageois). Le village s'étend de 3×3 → 10×10 parcelles de 7×7 cases via les fragments de carte ramenés des expéditions.

  ## Univers - 6 peuples

  | Peuple | Zone | Caractéristiques |
  |--------|------|------------------|
  | Perséphins | Plaines centrales | Marchands nomades, sociaux |
  | Yōtl | Dunes de sable | Guerriers, code d'honneur |
  | Arynes | Forêts écarlates | Artistes, festifs |
  | Kaprass | Montagnes | Astrologues, isolés |
  | Khétus | Côtes | Navigateurs, pêcheurs |
  | Primoris | Espace | Colons, technologie avancée |

  Cinq peuples = cinq biomes jouables avec ressources, ennemis et ambiance propres. Les Primoris sont la cause involontaire de la corruption.

  ## Mécaniques village

  Cinq bâtiments clés :

  - **Arbre de vie** - Bâtiment central, plafonne le niveau des autres bâtiments
  - **Habitation** - Augmente la capacité de villageois
  - **Hôpital** - Purifie les villageois corrompus + soigne les héros
  - **Forge** - Craft d'équipement (T1-T4) + reroll de stats via gemmes
  - **Caserne** - Lance les **excursions** (1-3 héros en autonomie)

  ## Mécaniques expédition

  - **5 biomes × 4 zones** + mode **Endless** débloqué après zone 16
  - **5 classes de héros** : DPS, Tank, Healer, Récolteur, Chercheur de trésor
  - **Tiers T1-T5** sur ressources, équipement et traits
  - **6 couleurs de gemmes** pour reroll (incolore = matériau, colorées = bloquent un trait)
  - **5 types de puzzles** : Piano, Plaque, Caisse-Plaque, Tangram, Memory
  - Stats riches : armure, force, vitesse, fortune, chance, critique, combo, enchaînement, portée…

# Ruins Of Hestia

Jeu en équipe développé pour les Gaming Campus Awards 25-26. Rôle dev sur l'engine custom C++/Vulkan.

## Contexte

Grand Projet Commun Bachelor 3A. 17 personnes réparties sur cinq pôles (Tech, Art, Business, TV, Sound). Production sur cinq mois de janvier à fin avril 2026.

## Concept

Hybride **management** + **action/exploration**. On gère un village de Perséphins en vue isométrique drag & drop, et on part en expéditions vue isométrique fixe ZQSD pour récolter des ressources, combattre la corruption et avancer dans l'histoire de Cali.

Cinq biomes jouables (un par peuple), 5 classes de héros, système de tiers T1-T5 sur tout (ressources, équipement, traits), reroll par gemmes colorées, puzzles intégrés (Piano, Plaque, Caisse, Tangram, Memory), mode endless après la zone 16.

## Stack & engine

C++20, Vulkan 1.3, CMake + vcpkg. Engine custom : 5 libs (Framework, Render, Audio, Assets, Engine ECS) + scenes. Pipeline graphique avec shaders GLSL/SPIR-V, compute pour les particules GPU. Génération procédurale tile-based des maps d'expédition.
