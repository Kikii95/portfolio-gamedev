  ## Monorepo architecture

  Turborepo + pnpm workspace, 7 shared packages + 3 apps:

  ```
  apps/
  ├── web        (Next.js 15 SSG)
  ├── desktop    (Tauri v2 — Rust backend)
  └── mobile     (Capacitor 6 — P1)

  packages/
  ├── types       (shared models)
  ├── constants   (keys, durations, enums)
  ├── utils       (formatters, date helpers)
  ├── db          (Prisma client)
  ├── core        (timer state machine)
  ├── ui          (shadcn-based components)
  └── hooks       (shared React hooks)
  ```

  `@timebeat/*` imports via pnpm workspace paths. Incremental builds with Turborepo.

  ## Offline-first

  The timer has to keep running without network. Architecture:

  - Zustand state persisted locally (`localStorage` on web, native Tauri store on desktop)
  - Sessions queued in an **outbox** when offline
  - On reconnect: flush to Supabase, conflicts resolved by `updatedAt`
  - Local SQLite on desktop for long-term history

  ## Timer state machine

  Pure logic isolated in `@timebeat/core`:

  ```
  idle ──start──► running ──pause──► paused
                     │                  │
                     ├──stop──► idle ◄──┘
                     │
                     └──tick──► running (elapsed +1s)
  ```

  Supports free timer OR time-boxed (Pomodoro-ready). Serializable state for crash recovery.

# Timebeat

Multi-platform time tracker built for devs and creatives: web, desktop, mobile, one account, one state.

## Context

Personal project bootstrapped early March 2026, MVP shipped 12/03, v1.0.3 on 13/03. On pause while prepping the v1.1 goals system.

## Why another tracker

Existing tools force one mechanic (strict Pomodoro, manual timer, or intrusive auto-tracking). Timebeat offers a **free timer OR time-boxed** mode chosen per session, a clean visual dashboard, and real cloud sync via Supabase — without having to host a backend.

## What works

**Web** — Next.js SSG, Supabase magic-link auth, project/task CRUD, timer, Recharts dashboard, user settings.

**Desktop** — Tauri v2 app (~20 MB), same UI as web, deeper integration planned for v1.2 (global shortcuts, tray icon).

**Mobile** — Capacitor in place, Android build validated. P1 phase.
