# Mini Studio: Pygame platformer

2D platformer developed as a team during the 1st-year "Mini Studio" project (April 2024).

## Context

Group project on a shared repository, one branch per member (programming and art), merged into the main branch for
the final hand-in.

## What I did

Player movement (jump, glide, run, gravity), the camera, the parallax background, character animations and item
pickup with an inventory.
