  ## Architecture monorepo

  Turborepo + pnpm workspace, 7 packages partagés + 3 apps :

  ```
  apps/
  ├── web        (Next.js 15 SSG)
  ├── desktop    (Tauri v2 - Rust backend)
  └── mobile     (Capacitor 6 - P1)

  packages/
  ├── types       (modèles partagés)
  ├── constants   (clés, durées, enums)
  ├── utils       (formatters, date helpers)

  ├── core        (state machine timer)
  ├── ui          (composants shadcn-based)
  └── hooks       (React hooks partagés)
  ```

  Imports `@timebeat/*` via les paths du workspace pnpm. Build incrémental via Turborepo.

  ## Offline-first

  Le timer doit pouvoir tourner sans réseau. Architecture :

  - State Zustand persisté localement (`localStorage` web, store Tauri natif desktop)
  - Sessions queued dans une **outbox** quand offline
  - À la reconnexion : flush vers Supabase, gestion des conflits par `updatedAt`
  - SQLite local sur desktop pour l'historique long

  ## State machine timer

  Logique pure isolée dans `@timebeat/core` :

  ```
  idle ──start──► running ──pause──► paused
                     │                  │
                     ├──stop──► idle ◄──┘
                     │
                     └──tick──► running (élapsed +1s)
  ```

  Support timer libre OU time-boxed (Pomodoro-ready). État sérialisable pour reprise après crash.

# Timebeat

Tracker de temps multi-plateforme pensé pour devs et créatifs : web, desktop, mobile, avec un même compte et le même état.

## Contexte

Projet personnel bootstrappé début mars 2026, MVP shippé le 12/03, v1.0.3 le 13/03. En pause pour préparer la phase v1.1 (système de goals).

## Pourquoi un nouveau tracker

Les outils existants forcent une mécanique unique (Pomodoro strict, timer manuel, ou auto-tracking intrusif). Timebeat propose un **timer libre OU time-boxed** au choix par session, avec un dashboard visuel sobre et une vraie sync cloud via Supabase - sans devoir héberger un backend.

## Ce qui marche

**Web** - Next.js SSG, auth magic-link Supabase, CRUD projet/tâche, timer, dashboard avec charts Recharts, paramètres user.

**Desktop** - App Tauri v2 (~20 MB), même UI que web, intégration plus poussée prévue pour la v1.2 (raccourcis globaux, tray icon).

**Mobile** - Capacitor en place, build Android validé. Phase P1.
